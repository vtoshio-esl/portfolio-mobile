# Portfolio Mobile
> Desenvolvido em React Native durante o curso de formação em desenvolvimento React Native da DIO

## Principais Tecnologias

- React Native Paper: utilizado para definir o esquema padrão de cores da tema aplicação (primary, secondary e cores default)
- React Native Navigator: Gerenciar a navegação entre telas da aplicação
    - StackNavigator: navegação em pilhas para separar a tela da home a tela de habilidades
    - TopTabsNavigator: navegação para uma navegação dinâmica entre as categorias das habilidades (front-end e back-end)
